This is a guide on how to review a draft for common writing habits that can be recognized by readers. The reviewer's job is to identify these habits and report them, without rewriting or suggesting alternative text. The draft is a technical article about the MCP protocol and its implementation.

The reviewer should follow these steps:

1. Read the entire draft, paying attention to each section equally.
2. Use a linter report, if available, to identify word-level habits such as hedges, emphasis words, and reader instructions. If no report is available, use the `ai-sniffer check` command to generate one.
3. Identify structural habits, which are not caught by linters and require manual inspection.
4. Ignore code, commands, tables of data, and quoted text from other sources.
5. Use the habit names and examples provided in the guide to identify the habits in the draft.
6. Quote the exact words from the draft that carry the habit, along with the line number where the quote starts.
7. Report each habit separately, indicating the severity level (high, medium, or low) and the quote.
8. Avoid suggesting replacement text or proposing alternative versions.
9. Do not imply who wrote the draft or suggest that the author is responsible for the habits.

The guide provides examples of the habits to look for, including:

* Antithesis: Setting up one idea only to knock it down for another.
* Fragment: Verbless phrases standing in for sentences.
* Triad: Three items, three clauses, or three adjectives used because three sounds finished, not because there were three things.
* Dramatic beat: A very short sentence or one-line paragraph placed to create a pause or reveal.
* Closer: A section or paragraph ending built to land a point.
* Restatement: The same point made twice in adjacent sentences, the second adding nothing.
* Cliche emphasis: Stock phrases that announce importance instead of showing it.
* Generic detail: A vague phrase where a real detail belongs.
* Reader instruction: Telling the reader how to think or react.
* Hedge: A universal claim softened so it can't be checked.
* Emphasis word: Intensifiers that add stress but no information.

The reviewer should use the provided examples to identify the habits in the draft and report them according to the guidelines.
